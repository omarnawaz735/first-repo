# Project preferences

## Before building any app

Always do these two things first, before writing code:

1. **Ask about the stack.** Confirm language, framework, runtime, styling, data store, and any deployment target. Don't assume defaults — ask.
2. **Discuss the workflow.** Walk through how the user will interact with the app: entry points, main screens/commands, data flow, persistence, and edge cases. Confirm the workflow with the user before implementing.

Only start building once both have been agreed on.
